# 🚀 INICIO RÁPIDO

## ⚡ En 5 minutos

### 1. Abre el panel admin
```
http://tu-sitio.com/admin/pages/dashboard/index.php
```

### 2. Verifica los cambios
- ✅ Navegación tiene iconos (📊 📺 🎥 etc.)
- ✅ Dashboard está reorganizado
- ✅ Acciones rápidas están agrupadas

### 3. Prueba una búsqueda
- Abre cualquier lista (películas, series, etc.)
- Escribe en el buscador
- La tabla se filtra automáticamente

### 4. Prueba un formulario
- Crea una nueva película
- Verifica que haya placeholders
- Verifica el contador de caracteres
- Verifica la validación visual

### 5. Prueba una alerta
- Guarda algo
- Verifica que la alerta sea verde (éxito)
- Intenta guardar sin completar campos
- Verifica que la alerta sea roja (error)

## 💡 Tips

### Búsqueda rápida
- Escribe solo parte del nombre
- Ej: "Ava" para encontrar "Avatar"

### Validación
- Espera a que el campo se ponga verde
- Lee los mensajes de error

### Navegación
- Usa los iconos para navegar rápido
- Pasa el mouse para ver tooltips

### Dashboard
- Usa las acciones rápidas para crear contenido
- Revisa las estadísticas para tener una visión general

## ❓ Preguntas frecuentes

### ¿Cómo busco en una tabla?
Escribe en el campo de búsqueda y la tabla se filtra automáticamente.

### ¿Cómo sé si un campo es requerido?
Los campos requeridos tienen un asterisco (*) rojo.

### ¿Cómo veo el preview de una imagen?
Selecciona una imagen en el formulario y verás el preview automáticamente.

### ¿Cómo cierro una alerta?
Las alertas se cierran automáticamente después de 5 segundos.

### ¿Qué significa cada icono?
Cada icono representa una sección del admin.

## 🐛 Problemas comunes

### Los iconos no se ven
- Recarga la página (Ctrl+R)
- Limpia el caché (Ctrl+Shift+Delete)

### La búsqueda no funciona
- Abre la consola (F12)
- Busca errores en rojo
- Recarga la página

### Los formularios no se validan
- Abre la consola (F12)
- Busca errores en rojo
- Recarga la página

---

## 📞 Soporte

Si tienes problemas:
1. Abre la consola (F12)
2. Busca errores en rojo
3. Intenta en otro navegador
4. Recarga la página
